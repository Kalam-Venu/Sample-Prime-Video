# Prime Video

A responsive Prime Video-style web application built with React. The application displays movies in categorized carousels and allows users to watch a selected movie in a popup video player.

## Features

* Displays Action and Comedy movie categories
* Responsive movie carousels using React Slick
* Next and Previous navigation for movie sliders
* Movie thumbnail selection
* Popup video player for selected movies
* Close button to exit the video popup
* Responsive layout

## Technologies Used

* React.js
* JavaScript
* CSS
* React Slick
* React Popup
* React Player
* React Icons

## Concepts Practiced

* React Components
* Props
* `map()` and `filter()`
* Third-party React packages
* React Slick carousels
* Popup modals
* Video playback with React Player
* Responsive CSS

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Kalam-Venu/Sample-Prime-Video.git
```

### Navigate to the project

```bash
cd Sample-Prime-Video
```

### Install dependencies

```bash
npm install
```

### Start the application

```bash
npm start
```

The application will run locally at:

```text
http://localhost:3000
```

## Project Highlights

This project demonstrates how multiple third-party React libraries can be combined to build an interactive user interface.

* **React Slick** — Used for movie carousels.
* **React Popup** — Used to display the movie player in a modal.
* **React Player** — Used to play the selected movie.
* **React Icons** — Used for interface icons such as the popup close button.
